# Regras de negócio

Registro de todas as regras que o app aplica. Cada regra aponta para onde está implementada e testada. **Regra nova ou alterada entra aqui na mesma tarefa** (ver `CLAUDE.md`).

## Convenções do Redmine da empresa

| Regra                                                                                                                                                                                                         | Onde                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| Versão `X.Y` é sprint; `X.Y.Z` é correção na branch da qualidade (staging) da sprint `X.Y`; outros nomes são agrupadores. Os padrões são regex configuráveis.                                                 | `domain/sprint/sprint-classifier.ts`     |
| Só "Finalizada" é status fechado; "Resolvida" e "Em teste" continuam abertos.                                                                                                                                 | Redmine (lido de `/issue_statuses.json`) |
| Datas da sprint vêm de campos personalizados da versão, detectados pelo nome: `limite\|dev` = prazo dos devs; `publica\|lança\|release\|deploy` = publicação. Sem campo de publicação, vale a data da versão. | `detectDateFields`                       |

## Início (fila de trabalho)

| Regra                                                                                                                                         | Onde                      |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------- |
| **Parada**: sem atualização há N dias (padrão 5, configurável) **ou** com status que contém pausa/bloque/aguard/impedi (ou pause/block/wait). | `domain/redmine/queue.ts` |
| **Atrasada**: data prevista no passado e tarefa não fechada.                                                                                  | `isOverdue`               |
| **Prioridade alta** (indicador): tarefas da fila com prioridade alta, urgente ou imediata.                                                    | `isHighPriority`          |
| **Prazos**: vencidas ou vencendo nos próximos 7 dias.                                                                                         | `analyzeQueue`            |

## Anexos

| Dentro do app: imagens que o Chromium desenha (PNG, JPG, GIF, WebP, BMP, SVG, ICO, AVIF) até 15 MB e texto até 2 MB (mostra até 200 mil caracteres). HEIC e TIFF vão para o app do sistema.                                                | `canPreview`, `PREVIEW_MAX_BYTES`, `TEXT_PREVIEW_CHARS` |
| O tipo da imagem vem dos primeiros bytes do arquivo, nunca do nome nem do Redmine; bytes que não são imagem não são mostrados. Texto com byte nulo no começo é tratado como binário e não é mostrado.                                      | `sniffImageType`, `looksBinary`                         |
| Texto em UTF-8; se não for UTF-8 válido, Windows-1252 (arquivos de ferramentas antigas do Windows).                                                                                                                                        | `decodeText`                                            |
| App do sistema: imagem, PDF, texto, vídeo, áudio, documento, planilha e apresentação, até 200 MB; **nunca** compactados nem extensões que executam ao abrir (programas, scripts, páginas, SVG, Office com macro). O resto abre no Redmine. | `canOpenInSystem`, `RUNNABLE_EXTENSIONS`                |
| Nome, tipo e tamanho são lidos do Redmine pelo id antes de mostrar ou abrir, então as regras valem para o arquivo real e não para o que a tela informou.                                                                                   | `AttachmentUseCases`                                    |
| Nome gravado em disco: sem pastas, sem caracteres reservados, até 120 caracteres mantendo a extensão.                                                                                                                                      | `safeFileName`                                          |

## Horas

| Regra                                                                                                                                                                                                 | Onde                                                       |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Horas digitadas como `1,5`, `1.5`, `2h`, `1:30`, `1h30`, `1h 30m`, `90m` ou `20 min`; o resultado tem duas casas (20 min = 0,33 h). Texto que não é duração é recusado.                               | `parseHours`                                               |
| Lançamento: mais de 0 e até 24 h, data real (qualquer data, passada ou futura), comentário obrigatório e uma tarefa. Arredondamento livre.                                                            | `assertValidDraft`                                         |
| Atividade (tipo de trabalho do Redmine, não a tarefa): a última usada neste computador; senão a padrão do Redmine; senão a primeira. Inativas não aparecem; com uma só, o campo some.                 | `defaultActivityId`, `ReferenceDataQueries.timeActivities` |
| Só os próprios lançamentos podem ser editados ou excluídos pelo app.                                                                                                                                  | `TimeEntryRow`                                             |
| Cronômetro: um por vez; começar outro descarta o anterior, depois de confirmar. Guarda só instantes (início, pausas), então sobrevive a reiniciar o app.                                              | `TimerService`, `startTimer`                               |
| Pausa sozinho quando o computador dorme ou a tela é bloqueada. Depois de 10 min sem teclado e mouse (verificado a cada minuto), pausa a partir do momento em que a pessoa saiu: esse tempo não conta. | `TimerService.onSleep`, `checkIdle`, `IDLE_LIMIT_SECONDS`  |
| Parar = pausar e abrir o lançamento com o tempo contado (duas casas, no mínimo 0,01 h, porque o Redmine recusa 0). O cronômetro só some quando o tempo é lançado ou descartado.                       | `TimerService.stop`, `elapsedHours`                        |
| Semana de "Minhas horas" começa no dia configurado na Agenda; linhas por tarefa, da que tem mais horas para a que tem menos.                                                                          | `weekDays`, `buildTimesheet`                               |
| "Repetir semana passada": os lançamentos com tarefa da semana anterior, de novo 7 dias depois (mesma tarefa, horas, atividade e comentário), um por um; não verifica se já foram repetidos.           | `RepeatWeekUseCase`, `shiftedEntries`                      |

## Filtro por URL

| Regra                                                                                                                                                                                            | Onde                 |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------- |
| Aceita o endereço de qualquer lista de tarefas do Redmine (`…/issues?…` ou `…/projects/<id>/issues?…`), com ou sem o host; os parâmetros são repassados para `/issues.json`.                     | `parseIssuesUrl`     |
